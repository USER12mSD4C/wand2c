## Editorial rule

These documents describe the compiler in this repository. Syntax rules are defined in [SYNTAX.md](SYNTAX.md). Tutorial text does not restate the full reference. Implementation limitations are recorded in [TROUBLESHOOTING.md](TROUBLESHOOTING.md) and in the relevant reference section.
